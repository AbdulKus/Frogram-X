<h1 align="center">Frogram X</h1>

<p align="center">
  Независимый форк Telegram X для Android на базе TDLib.
</p>

## Что изменено

- отдельное имя и идентификатор приложения `org.frogram.messenger` — Frogram X можно установить рядом с оригинальным Telegram X;
- поддержка топиков: отдельная история, непрочитанные и закреплённые сообщения, создание, редактирование, закрытие и удаление при наличии прав;

Frogram X находится в разработке. Перед обновлением рекомендуется сохранять резервную копию важных данных и ключа подписи APK.

## Скачать сборку

Откройте [GitHub Actions](https://github.com/AbdulKus/Frogram-X/actions/workflows/android.yml), выберите последнюю успешную сборку **Build Frogram X** и скачайте артефакт `Frogram-X-…`.

Артефакты хранятся 30 дней. Рядом с APK публикуется файл `SHA256SUMS.txt` для проверки контрольной суммы.

## Обновления в приложении

**Настройки → Обновления → Автоматически проверять обновления** включает проверку GitHub Releases при открытии приложения, не чаще раза в шесть часов. Выключатель не мешает ручной проверке.

В списке чатов появляется небольшая полоска «Доступно обновление» с кнопкой «Что нового». Окно показывает описание релиза; кнопка «Скачать» запускает загрузку с прогрессом, после неё доступна кнопка «Установить». Загрузка продолжается при закрытии окна и приложения. Android запрашивает обычное подтверждение установки.

«Позже» скрывает напоминание об этом релизе на сутки. Окно всегда можно открыть снова в настройках обновлений.

APK проверяется по SHA-256, пакету, версии и подписи установленного приложения. Скачивание начинается только по нажатию кнопки. Постоянного фонового сервиса для проверки обновлений нет.

## Автоматическая сборка

Workflow `.github/workflows/android.yml` запускается при изменениях в `main`, для pull request в `main` и вручную через `workflow_dispatch`.

Для постоянной подписи APK добавьте в **Settings → Secrets and variables → Actions**:

- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Release-сборка требует постоянный ключ подписи. Для pull request без секретов допускается временная тестовая подпись; такой APK несовместим с обновлением поверх основного релиза. Храните исходный keystore и пароли в защищённых резервных копиях.

После успешной сборки `main` Actions публикует релиз с APK, `SHA256SUMS.txt`, `update.json` и автоматически сформированным описанием изменений. Релиз становится видимым только после загрузки всех файлов. Манифест обновления строится из настоящих данных APK. Базовый номер Android-версии равен `version.app + GITHUB_RUN_NUMBER`, поэтому последовательные сборки отличаются даже без обновления версии Telegram X.

Для push-уведомлений зарегистрируйте Android-приложение `org.frogram.messenger` в бесплатном проекте Firebase, скачайте `google-services.json` и добавьте его в secret `GOOGLE_SERVICES_JSON_BASE64` в виде одной base64-строки. Без этого секрета release собирается, но Firebase Cloud Messaging отключается.

## Локальная сборка

Требуются Git с LFS, Java 21, Android SDK/NDK и стандартные инструменты сборки Linux.

```bash
git clone --recursive https://github.com/AbdulKus/Frogram-X.git
cd Frogram-X
scripts/setup.sh
./gradlew assembleLatestArm64Debug
```

Telegram API ID и hash можно получить на [my.telegram.org](https://my.telegram.org). Дополнительная информация об исходной архитектуре и зависимостях доступна в [руководстве разработчика](docs/GUIDE.md) и [списке сторонних компонентов](docs/THIRDPARTY.md).
